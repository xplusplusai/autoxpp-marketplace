# D365 Customer Engagement / Dataverse - Browser Automation Reference

## Site Info
- **Site key:** `d365-ce`
- **URL pattern:** `*.crm.dynamics.com`
- **Auth type:** Microsoft Entra ID (SSO)
- **Framework:** D365 UCI (Unified Client Interface)
- **Last updated:** 2026-04-25

## Navigation Patterns

| Destination | Method | Notes |
|:------------|:-------|:------|
| Entity list (e.g., Products) | URL: `?pagetype=entitylist&etn={entity}` | e.g., `etn=product` |
| Entity record | URL: `?pagetype=entityrecord&etn={entity}&id={guid}` | Direct open by GUID |
| Search within list | Use the keyword searchbox at top of list view | Searches across Name and Product ID columns; press Enter to execute |

### Product Form Tab Layout

CE product form (`etn=product`) has these tabs in order:

| Tab | Key Fields |
|:----|:-----------|
| **Product Details** | Name, Product Number, Description, Valid From/To, Product Size/Configuration/Style/Color, Cost Group Financial Dimension, Terms, Service Agreement Group, Unit Group, Default Unit, Default Price List, Decimals Supported, Project Category, Project Transaction Type, Subject |
| **Product Properties** | Properties grid (from Product Families) — usually empty for standalone products |
| **Additional Details** | Price List Items subgrid (Price List, Unit, Pricing Method, Amount), Product Relationships subgrid, Linked Articles |
| **Notes** | Timeline / activity notes |
| **Field Service** | Field Service Product Type (locked), UPC Code, Convert to Customer Asset, Vendor, Purchase Name, Current Cost, Standard Cost |
| **Integration** | Item Number, Company (lookup), Shared Product Detail (lookup), Product Type, Is Stocked Product |
| **Admin** | Source Opportunity GUID, Manufacturer Part Number |
| **Related** | Related entities navigation |

### Fields NOT on Visible Form Tabs

Some CE fields that exist on the entity are **not placed on any form tab**. They're only accessible via API (OData/Dataverse). Known examples:
- Custom fields (e.g. `{prefix}_productmanufacturer`) — not on any tab; verify via IntegrationCompare API only
- `msdyn_taxable` — not visible; verify via API
- `isstockitem` — not visible; `msdyn_isstockedproduct` is on the Integration tab instead

## Form Interactions

### List View Search
1. Find `searchbox "Product Filter by keyword"` in snapshot
2. `playwright-cli fill {ref} "{search term}"` — type the search value
3. `playwright-cli press Enter` — execute the search
4. Results appear in the grid below; click link in Name column to open record

### Tab Navigation
- Tabs are `tab` role elements in the snapshot — click by ref
- Active tab shows `[active] [selected]` attributes
- Tab content loads in a `tabpanel` element below the tablist
- CE tabs load faster than FO (~2-3s vs 8-12s) — a short sleep (2s) is sufficient

### Lookup Fields
- Lookup fields show as `list` with `listitem` children (selected values)
- Each value has a `link` (to open) and `button "Delete {value}"` (to remove)
- Empty lookups show as `combobox` with `"---"` placeholder
- Search button: `button "Search records for {FieldName}, Lookup field"`

### Combobox/Option Set Fields
- Option sets render as `combobox` with current text value visible
- Click to open dropdown, then click the option

### Header Flyout
- `button "More Header Editable Fields"` expands a flyout above the tabs
- Shows header-level fields (e.g., Status) — limited set, not all fields
- Press Escape to close

## Known Quirks & Workarounds

| Issue | Workaround |
|:------|:-----------|
| **CE page load timing** | CE pages render in 2-3s (much faster than FO). A `sleep 2` before snapshot is usually sufficient after navigation or tab click. |
| **Search box retains previous value** | After navigating back to list, the searchbox keeps the old search term. Click "Clear search" button (ref changes each time) before entering new search. |
| **playwright-cli `press` takes no element ref** | `playwright-cli press {ref} {Key}` errors with "too many arguments". Use `playwright-cli press {Key}` only — it sends to the focused element. To target a specific element, click it first. |
| **Login identity split** | CE may use a different account than FO. Check `ude-configs.json` for the correct login per environment. Verify the correct account is selected on the "Pick an account" page. |
| **MFA poll detection** | After bringing browser to foreground for MFA, poll the page URL (not snapshot) every 5s: `playwright-cli eval "window.location.href"`. Login complete when URL no longer contains `login.microsoftonline.com`. Snapshot-based detection is unreliable during MFA flow. |
| **Password not auto-filled** | With `--persistent` profile, email may auto-fill but password may not (browser credential manager doesn't always save CE credentials). Click Sign in first to test — if "Please enter your password" error appears, bring browser to foreground for manual entry. |
| **Auth state save location** | Save CE auth state to `{ProjectMemoryDir}/auth-state/d365-dev3-ce.json` (or `d365-bat-ce.json` for BAT). Separate from FO auth state due to identity split. |
| **"Choose an app" banner** | CE shows a dismissible banner "For the best experience viewing this content, open it in a specific application." Ignore it — does not block automation. |
| **Auto publish notification** | Product forms show "Auto publish is enabled" alert. Informational only, no action needed. |

## Lessons Learned

| Context | Learning |
|:--------|:---------|
| Product search | CE list view searchbox searches across multiple columns (Name, Product ID). Just type the item number and press Enter — works for both product name and product number searches. |
| Tab verification | After clicking a tab, verify `[active] [selected]` in snapshot before reading tab content. Tab content is in `tabpanel "{TabName}"`. |
| Back navigation | `button "Press Enter to go back."` returns to list view from a record. The button text is literal — click it by ref. |
| Record identification | CE products use GUID-based URLs. Product Number is `msdyn_productnumber`, but the Product ID shown in list grids is prefixed (e.g., "CBGM000325" = company prefix + item number). |
| Field visibility vs API | Not all mapped integration fields appear on the CE form. Use IntegrationCompare function for definitive field-by-field verification; use browser for visual confirmation of fields that ARE on the form. |
