# AutoXPP Load QA Engineer

Loads the QA Engineer persona for interactive pre-lifecycle work -- test planning, test data strategy, coverage analysis, and test matrix design.

## Why This Skill Matters

Test planning benefits from a dedicated expertise profile. When designing test coverage for a complex requirement, the agent needs to think about edge cases, data dependencies, environment constraints, and verification strategies -- not implementation details. This skill loads the QA Engineer persona so the agent focuses on what to test and how to verify it, before the autonomous lifecycle generates test cases automatically.

## When to Use

Invoke when working interactively on testing and quality topics:
- Designing a test plan for a complex requirement
- Analyzing test coverage gaps
- Planning test data setup strategies
- Reviewing test cases for completeness
- Discussing verification approaches (OData vs. SQL vs. browser)

## Invoke

`/autoxpp-load-qa-engineer`
