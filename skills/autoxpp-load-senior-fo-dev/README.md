# AutoXPP Load Senior FO Dev

Loads the Senior D365 F&O Developer persona for interactive pre-lifecycle work -- investigation, debugging, code research, and solution design.

## Why This Skill Matters

Pre-lifecycle work (before committing to the autonomous code-build-test loop) requires a different operating mode than autonomous execution. The developer needs to explore code, read standard D365 patterns, trace call stacks, query data, and discuss approaches with the user. This skill configures the agent with the right expertise profile for that interactive phase: deep X++ knowledge, D365 platform conventions, extension design patterns, and debugging methodology.

## When to Use

Invoke when working interactively on D365 F&O topics outside the autonomous lifecycle:
- Investigating a bug report or unexpected behavior
- Reading and understanding standard D365 code
- Designing a solution approach before starting the lifecycle
- Debugging a build failure or runtime error
- Answering X++ or D365 platform questions

## Invoke

`/autoxpp-load-senior-fo-dev`
