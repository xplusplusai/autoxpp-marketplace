# AutoXPP Load Integration Dev

Loads the Senior Integration Developer persona for interactive pre-lifecycle work -- Azure Functions, Service Bus, Dataverse plugins, OData mappings, and cross-system data flows.

## Why This Skill Matters

Integration work spans multiple technology stacks and requires a different expertise profile than D365 X++ development. When investigating an inbound EDI pipeline, debugging a Service Bus message handler, or designing an OData entity mapping, the agent needs fluency in Azure Functions, Dataverse plugin patterns, message queue architectures, and the D365 OData/Data Entity framework. This skill loads that profile so the agent operates with the right context for integration-focused work.

## When to Use

Invoke when working interactively on integration topics:
- Investigating Azure Functions or Logic Apps that connect to D365
- Debugging Service Bus message processing
- Designing Dataverse plugin workflows
- Mapping OData entities to external system contracts
- Reviewing cross-system data flows and transformation logic

`/autoxpp-load-integration-dev`
